# SQL Data Warehouse & Business Reporting Pipeline

An end-to-end SQL Server data warehouse project focused on transforming transactional data into structured analytical datasets and business reporting outputs.

## Project Overview

The project follows a layered data warehouse approach:

```text
Bronze Layer
   ↓
Silver Layer
   ↓
Gold Layer
   ↓
Reporting Views
   ↓
Business Analysis
```

The workflow is designed to separate raw ingestion, cleaned/transformed data, and business-ready analytical data.

## Key Components

- Bronze–Silver–Gold data warehouse architecture
- Data loading and transformation
- Data cleaning and standardization
- Relational data modeling
- Analytical SQL queries
- Reporting views
- Business reporting datasets

## SQL Techniques Demonstrated

- INNER / LEFT JOINs
- Common Table Expressions (CTEs)
- Window Functions
- Aggregations
- Views
- Data transformation
- Data modeling
- Query optimization

## Reporting Workflow

1. Load transactional/source data
2. Organize raw data in the Bronze layer
3. Clean and transform data in the Silver layer
4. Build business-ready datasets in the Gold layer
5. Create SQL reporting views
6. Use analytical queries to generate reporting insights

## Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

This project demonstrates practical SQL and data warehousing skills relevant to Data Analyst, Reporting Analyst, BI Analyst, and entry-level Analytics roles.
